# KnowledgeForge

KnowledgeForge is an AI-powered personal knowledge management system designed
to organize, structure, search, and enrich a personal knowledge base.

## Project Status

The project is currently in the initial bootstrap stage.

The first development goal is to establish a clean, maintainable, and
production-oriented foundation before implementing the knowledge management
features.

## Requirements

- Python 3.12+
- uv
- Git

## Installation

Create and activate a virtual environment, then synchronize project
dependencies:

python -m uv sync
